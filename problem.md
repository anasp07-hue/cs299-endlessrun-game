Problem 
- There aren't many good games that you can play on a computer with no wifi. I want to make a 3d endless runner game that helps you kill time when your in a spot where wifi isn't available like a airplane.

Initial Requirments
- Able to run completly offline, game can't be super heavyweight and all game logic and processes can run in locally in the browser of any modern computer
- Actually fun and enjoyable
- Has things that make you want to keep playing like a highscore

Round 2 Requirements
- Shards save after closing like how the high score does
- Game can still run completly offline with no build phase
- Nothing else breaks and runs are still smooth

Round 3 Requirements
- Add a simple shop where we can buy characters with the saved shards
- 2 new characters a silver robot/andriod character and a green alien
- Same movement and hitbox & nothing breaks
- Skins don't save
