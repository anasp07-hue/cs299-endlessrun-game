Problem 
- There aren't many good games that you can play on a computer with no wifi. I want to make a 3d endless runner game that helps you kill time when your in a spot where wifi isn't available like a airplane.

Initial Requirments
- Able to run completly offline, game can't be super heavyweight and all game logic and processes can run in locally in the browser of any modern computer
- Actually fun and enjoyable
- Has things that make you want to keep playing like a highscore

Round 2 Requirements
- Shards save after closing like how the high score does
- Game can still run completly offline with no build phase
- Nothing else breaks and runs are still smooth

Round 3 Requirements
- Add a simple shop where we can buy characters with the saved shards
- 2 new characters a silver robot/andriod character and a green alien
- Same movement and hitbox & nothing breaks
- Skins don't save

Round 4 Requiements
- Add 3 power ups, a bazooka that destroys obstacles, double score, and phasing through obstacles
- Bazooka has one shot that destroys the next row of obstacles
- Double score and phase last for 30 seconds
- They get picked up off the ground
- Spawn is random but rare, they don't spawn a lot
- Nothing breaks and powerups do what they are supposed to

Round 5 Requirments
- Power ups are imbalanced make it so phase lasts 5 seconds
- If you pick up a power up the next spawn won't be the same one
- Make it so the skins you buy save after exiting, but they are now more      expensive

Round 6 Requirements
- Add some voicelines for the agent
- Should sound like a middle aged man
- Triggered at the start of the run, on stumble, and when caught
- Each thing should have 3-5 unique voice lines
- Easy way to hear each one
- Nothing external make it the same way you made the sfx
